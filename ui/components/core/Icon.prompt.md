Inline Lucide glyph sized from the icon scale — use it anywhere Apuriva needs an icon rather than hand-rolling SVG.

```jsx
<Icon name="map-pin" size="sm" color="var(--text-muted)" />
<Icon name="shield-check" size="md" color="var(--verified)" title="Verified provider" />
```

Sizes: `xs` 14 / `sm` 16 / `md` 20 / `lg` 24 / `xl` 32, or a raw pixel number. Decorative by default; supply `title` only when the icon carries meaning no adjacent text repeats. 50 glyphs are bundled — see assets/icons/.
