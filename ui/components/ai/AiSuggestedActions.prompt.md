Low-noise next steps offered by the assistant. Suggestions, never commitments — tapping one starts a flow, it does not perform a high-risk action.

```jsx
<AiSuggestedActions actions={[
  {label:'Compare these 3 offers',icon:'chart-column'},
  {label:'Ask about warranty',icon:'message-circle'},
  {label:'Book the top match',icon:'calendar'}]} onSelect={run} />
```
